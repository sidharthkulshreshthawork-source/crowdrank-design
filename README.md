# CrowdRank

**Social prediction game — playable practice MVP in progress.**

CrowdRank invites players to rank four options in each of three rounds, earn up to 18 points, and challenge a friend. The working game and design documents are being added on the `feat/playable-mvp` branch.

Practice orders are fictional examples, **not** independently surveyed public opinion. Competitive rankings, live audience votes, authenticated duels and monetization require a future backend and real voting panel.
